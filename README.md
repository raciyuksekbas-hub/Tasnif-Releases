# Tasnif

**Belgeler yerini bulsun.**

Tasnif; UYAP'tan veya diğer kaynaklardan indirilen hukuki belgeleri bilgisayarınızın içinde analiz ederek doğru dava dosyaları altında düzenlemeye yardımcı olan ücretsiz masaüstü uygulamasıdır.

## Öne çıkanlar

- 🔒 Belgeler bilgisayardan dışarı çıkmaz
- 🤖 Yapay zekâ kullanılmaz
- 🔌 API gerekmez
- ☁️ Cloud upload yok
- 📂 Mahkeme/kurum ve dosya numarası tespiti
- 🗃️ Mevcut dava klasörünü bulma veya yenisini önerme
- ✅ Kullanıcı onayı olmadan dosya taşıma yok
- ↩️ Geri alma desteği
- 🍎 macOS (Apple Silicon)
- 🪟 Windows (x64)

## İndir

En güncel beta sürümü **[Releases](../../releases)** sayfasından indirebilirsiniz.

## Beta

Bu sürüm beta aşamasındadır. Kullanıcıların önemli belgeleri üzerinde kullanmadan önce uygulamanın önerdiği hedefleri kontrol etmeleri tavsiye edilir.
